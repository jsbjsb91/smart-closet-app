# Smart Closet Multi-Agent Team (`smart-closet-team`)

Paquete oficial de **7 agentes especializados**, **1 skill de gestión** y **reglas de dominio** para desarrollar, auditar, diseñar y desplegar **Smart Closet App**.

## Agentes Incluidos

1. **`orquestador-proyecto`**: Arquitecto y coordinador general del producto. Divide tareas complejas entre el equipo de especialistas y valida la coherencia final.
2. **`agente-diagnostico`**: Ingeniero de diagnóstico, depuración, rendimiento, cuota de `localStorage`, ciclo de vida de cámara y auditoría criptográfica (`PBKDF2` + `AES-256-GCM`).
3. **`agente-mejoras`**: Analista de innovación *Fashion-Tech* y experiencia de usuario (Prenda Ancla, Maleta Cápsula de Viaje, Analítica de Rotación).
4. **`experto-desarrollo`**: Ingeniero React & Full-Stack responsable de estado, multi-usuario, cámara `<canvas>` y seguridad.
5. **`experto-apariencia`**: Director de diseño UI/UX *mobile-first* con Tailwind CSS, tarjetas editoriales y micro-interacciones.
6. **`experto-ia-estilista`**: Especialista en algoritmos de recomendación de outfits, rotación anti-olvido, aprendizaje por refuerzo y visión por foto (`Gemini Vision` + análisis cromático local).
7. **`experto-qa-deploy`**: Responsable de compilación, pruebas de casos extremos y sincronización continua con GitHub y Vercel.
